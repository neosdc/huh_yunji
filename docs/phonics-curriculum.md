# 파닉스 웹 게임 커리큘럼 (초안 v0.1)

대상: 영어 읽기를 처음 시작하는 한국 초등학생
원칙: 글자 이름이 아니라 글자가 내는 소리를 연결한다. 한 단계에 새 소리는 4~6개까지, 이전 단계는 계속 섞어서 복습한다.
이 문서는 제안안이다. 단계 순서와 단어는 실제 학습자 반응을 보고 조정한다.

---

## 단계 개요

| 단계 | 주제 | 새로 배우는 소리/패턴 | 대표 단어 | 주 게임 유형 |
|---|---|---|---|---|
| 1 | 첫 글자 묶음 | s, a, t, p, i, n | sat, tap, pin, sit, nap, pan, tin, pit | 소리 맞추기, 첫소리 사냥 |
| 2 | 글자 묶음 2 | m, d, g, o, c, k | mat, dog, cot, kid, dig, mop, cap, pig | 소리 합치기, 단어 만들기 |
| 3 | 글자 묶음 3 | e, u, r, h, b | hen, bug, red, hug, bed, run, hot, rub | 단어 만들기, 라임 매칭 |
| 4 | 글자 묶음 4 | f, l, j, v, w, x, y, z, qu | fan, leg, jam, van, web, box, yes, zip | 첫소리 사냥, 소리 합치기 |
| 5 | 단모음 CVC 종합 | a, e, i, o, u 구분 | bat/bet/bit/bot/but, cap/cup | 중간소리(모음) 구분 게임 |
| 6 | 자음 두 글자 소리 | sh, ch, th, ck, ng | ship, chip, thin, duck, ring | 소리 합치기, 단어 만들기 |
| 7 | 자음 연속(블렌드) | bl, cl, fl, pl, sl / br, cr, dr, gr, tr / st, sp, sn, sk / -nd, -nt, -mp, -nk | flag, drum, stop, hand, lamp | 단어 만들기, 보스 스테이지 |
| 8 | 마법의 e | a_e, i_e, o_e, u_e | cake, kite, bone, cube | 짝 바꾸기(cap→cape) |
| 9 | 모음 팀 1 | ai, ay, ee, ea, oa, ow(긴 o) | rain, day, bee, leaf, boat, snow | 라임 매칭, 단어 만들기 |
| 10 | 모음 팀 2, r 모음 | oo, ou, ow(au), oi, oy, ar, or, er/ir/ur, aw | moon, cloud, coin, car, fork, bird | 소리 맞추기, 보스 스테이지 |
| 11 | 사이트 워드 | 규칙대로 읽히지 않는 고빈도 단어 | the, a, I, is, was, said, you, are | 카드 맞추기, 빠르게 읽기 |

사이트 워드는 단계 1부터 소량(2~3개)씩 섞어 넣고, 11단계에서 집중 복습한다.

## 단계별 상세

### 단계 1: s a t p i n
- 소리: /s/ /æ/ /t/ /p/ /ɪ/ /n/
- 6개 글자만으로 만들 수 있는 단어: sat, sit, sip, tap, tip, pin, pit, pat, nap, nip, tan, tin, pan, ant, at, an, in, it, is
- 게임: (A) 소리 듣고 글자 고르기 (B) 그림 보고 첫소리 고르기 (C) 소리 타일 눌러 단어 합치기
- 사이트 워드: I, a

### 단계 2: m d g o c k
- 소리: /m/ /d/ /g/ /ɒ·ɑ/ /k/ (c와 k는 둘 다 /k/)
- 단어: mat, map, dig, dog, got, cot, cap, kid, kit, mop, pig, dot, mad, can
- 주의: c는 이 단계에서 /k/ 소리만 다룬다(/s/ 소리는 나중에).
- 사이트 워드: the, to

### 단계 3: e u r h b
- 소리: /ɛ/ /ʌ/ /r/ /h/ /b/
- 단어: hen, pen, red, bed, bug, hug, run, rub, hot, hat, bus, hum, cub
- 주의: 한국 학생은 /r/을 한글 "ㄹ"로 읽기 쉬우므로 혀 모양 안내를 곁들인다.
- 사이트 워드: is, my

### 단계 4: f l j v w x y z qu
- 소리: /f/ /l/ /dʒ/ /v/ /w/ /ks/ /j/ /z/ /kw/
- 단어: fan, fun, leg, log, jam, jet, van, vet, web, win, box, six, yes, yet, zip, quit
- 주의: /f/-/p/, /v/-/b/, /l/-/r/은 한국어 화자에게 혼동되기 쉬운 쌍이므로 구분 연습 문제를 따로 둔다.
- 사이트 워드: you, are

### 단계 5: 단모음 CVC 종합
- 모음 소리 5개(a e i o u)를 가운데 모음만 바꿔 구분하는 연습
- 최소대립쌍: bat / bet / bit / bot / but, pan / pen / pin, cap / cup, hat / hit / hot
- 게임: 소리 듣고 단어 고르기(모음만 다른 선택지), 단어 만들기
- 보스: 1~5단계 전체 복습 문제 섞기

### 단계 6: sh ch th ck ng
- 소리: /ʃ/ /tʃ/ /θ, ð/ /k/(ck) /ŋ/
- 단어: ship, shop, fish, chip, chop, much, thin, this, that, duck, back, sing, ring
- 주의: th는 한국어에 없는 소리. 입모양(혀가 이 사이로 나옴) 일러스트 필수. 처음에는 /θ/와 /ð/를 구분하지 않고 th 하나로 제시해도 된다.

### 단계 7: 자음 연속(블렌드)
- 앞 블렌드: bl cl fl gl pl sl / br cr dr fr gr pr tr / st sp sn sk sm sw
- 뒤 블렌드: -nd -nt -mp -nk -st -ft -lt
- 단어: blue(제외 가능, 이중모음), black, clap, flag, plan, slip, brick, crab, drum, frog, grab, tree, stop, spin, skip, hand, tent, lamp, pink, nest, left
- 각 소리를 따로 들려준 뒤 이어 붙이는 블렌딩 연습이 핵심(/s/ /t/ /ɒ/ /p/ → stop)

### 단계 8: 마법의 e (a_e, i_e, o_e, u_e)
- 규칙: 단어 끝의 e는 소리가 없고, 앞 모음이 자기 이름 소리(긴소리)로 바뀜
- 쌍 예시: cap→cape, tap→tape, kit→kite, pin→pine, hop→hope, not→note, cub→cube, cut→cute
- 게임: e 카드를 끝에 붙이면 그림과 소리가 바뀌는 애니메이션, 짝 바꾸기 문제
- 단어: make, cake, game, bike, time, five, home, bone, nose, tube

### 단계 9: 모음 팀 1
- ai/ay(/eɪ/): rain, tail, train, day, play, say
- ee/ea(/iː/): bee, tree, feet, sea, leaf, read
- oa/ow(/oʊ/): boat, coat, road, snow, grow, slow
- 게임: 같은 소리를 내는 철자 묶기(라임 매칭), 단어 만들기

### 단계 10: 모음 팀 2, r 모음
- oo(/uː/·/ʊ/): moon, food, book, foot
- ou/ow(/aʊ/): cloud, house, cow, down
- oi/oy(/ɔɪ/): coin, oil, boy, toy
- ar, or, er/ir/ur: car, star, fork, corn, her, bird, turn
- aw/au: saw, paw, haul
- 주의: 영어 철자와 소리가 일대일이 아닌 영역이므로 높은 정확도를 요구하지 않고 "자주 나오는 패턴 익히기" 수준으로 접근한다.

### 단계 11: 사이트 워드
- 1차(단계 1부터 섞어 소개): I, a, the, to, is, my, you, are
- 2차: was, said, have, do, of, he, she, we, me, be, they, there, one, what, where, come, some
- 게임: 빠르게 읽고 맞추기, 문장 속 빈칸(I ___ a cat)

## 복습 규칙 (게임 로직용)
- 새 단계 문제 70%, 이전 단계 복습 30%
- 틀린 항목은 오답 목록에 저장하고, 같은 세션 안에서 2~3문제 뒤와 다음 접속 때 다시 출제
- 같은 항목을 연속 3회 맞히면 숙달 처리, 이후 복습 빈도를 낮춤
- 한 판은 2~3분, 문제 8~10개 정도
- 정답 시 즉시 소리 재생, 오답 시 정답 소리를 다시 들려주고 다음으로 넘어감(감점이나 큰 실패 연출은 피함)

## 콘텐츠 데이터 형식 (제안)

코드와 콘텐츠를 분리하기 위해 JSON으로 관리한다.

```json
{
  "stage": 1,
  "title": "s a t p i n",
  "phonemes": [
    { "id": "s", "grapheme": "s", "ipa": "/s/", "audio": "audio/phonemes/s.mp3" },
    { "id": "a", "grapheme": "a", "ipa": "/æ/", "audio": "audio/phonemes/a_short.mp3" }
  ],
  "words": [
    {
      "word": "sat",
      "phonemes": ["s", "a", "t"],
      "audio": "audio/words/sat.mp3",
      "image": "img/words/sat.svg"
    }
  ],
  "sightWords": ["I", "a"]
}
```

## 파일 이름 규칙 (제안)
- 음소: `audio/phonemes/{id}.mp3` (예: `b.mp3`, `sh.mp3`, `a_short.mp3`, `a_long.mp3`)
- 단어: `audio/words/{word}.mp3`
- 이미지: `img/words/{word}.svg`
- 음원은 파일만 교체하면 반영되도록 경로를 JSON에서만 참조한다.

## 음원 품질 체크리스트
- 파열음(/b/ /d/ /g/ /p/ /t/ /k/)에 "으/어" 모음이 딸려 들리지 않는지 귀로 확인
- 음소 길이 0.3~0.8초, 앞뒤 무음 최소화, 볼륨 통일
- 같은 글자가 여러 소리를 가질 때(a: 단모음/장모음) 파일을 분리
